# AI Tools

A generic tools compendium. I think I have a section on the general.md file,
and also I've linked tools to specific harnesses/agents, but since most tools
usually support several agents, I think it's better to start this section.

- [whiteboard](https://github.com/devdotfast/whiteboard)
  A code analysis tool that let's you visualize code flux with graphic charts
  and provides analysis and explanation of diffs, useful to analyze
  implementation of a new feature on a code base or to start familiarizing with
  one.
